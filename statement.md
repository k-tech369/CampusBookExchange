# Campus Book Exchange System

## Problem Statement

Students often have textbooks and academic books that they no longer need after completing a course or semester. At the same time, other students may need the same books but may not know who has them. There is no simple centralized system within the campus to manage book exchange and borrowing.

The Campus Book Exchange System provides a simple console-based Java application that allows students to register, add books, search for available books, borrow books, return books, and view transaction history.

## Scope of the Project

The project focuses on providing a basic campus-level platform for managing academic book exchanges. It includes student registration, book management, book searching, borrowing and returning, and transaction tracking.

The current version uses in-memory data storage and operates through a command-line interface. It does not include a database, online payments, authentication, or a graphical user interface.

## Target Users

* College and university students
* Students looking for academic books
* Students who want to exchange or lend unused books

## High-Level Features

* Student registration
* Adding books to the system
* Viewing all available books
* Searching books by title, author, or category
* Borrowing books
* Returning books
* Viewing transaction history
* Basic validation and error handling
* Console-based user interaction
